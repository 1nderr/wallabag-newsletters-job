# Wallabag Newsletters Job Privacy Policy

Wallabag Newsletters Job is a personal application used only by its developer. It is not offered to the public.

## Data accessed

With the user's authorization, the app accesses the following Google user data:

- Email data of the user

## Use

This data is used only to provide the app's functionality for the authorizing user.

## Storage

OAuth tokens and any retrieved data are stored locally on the developer's own machine and are not sent to any third-party server.

## Sharing

No data is sold, shared with, or transferred to third parties.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Limited Use

Wallabag Newsletters Job's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
